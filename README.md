# 遗物助手 · Electron

根据之前「遗物窗口」的功能记录重新实现。此项目为完整源码，不含已构建 EXE，也不包含你的旧遗物数据。

## Windows 使用

1. 安装 Node.js LTS（https://nodejs.org）。
2. 解压整个项目，双击 `start.cmd`。首次需要联网下载依赖，之后可离线启动。
3. 生成无需 Node.js 的便携 EXE：双击 `build-windows.cmd`，成品位于 `dist/RelicAssistant-1.5.0.exe`。

也可在项目目录执行 `npm install`、`npm start`；打包为 `npm run dist:win`。

## 操作

- 古纪、前纪、中纪、后纪四列；直接点击纪元和颜色按钮、输入名称，按 Enter 添加。
- 单击条目复制其完整文字；双击删除（双击期间也会触发复制）。底栏可撤销最后一次删除。
- 右键条目循环铜／银／金三种颜色。颜色由你手动设置。
- 右上角开启精简置顶、最小化、最大化／还原、关闭。
- 拖动顶部空白区域移动窗口，拖动边缘调整大小；无系统标题栏。
- 每次改动自动保存，窗口位置也会保存。
- 导出／导入 JSON 备份；导入需确认，替换前会自动备份原列表。

## 数据位置

数据自动保存到 `%APPDATA%\relic-assistant\data`（Electron 的 userData 目录）。EXE 旁不再生成 data 文件夹。数据实际存于 Windows 用户目录，不写入 EXE 内部；移动或更新 EXE 不影响同一 Windows 用户的数据，复制 EXE 到其他电脑不会带走数据，请使用导出／导入备份。

首次启动新版时，如果新位置尚无 saved_texts.json，会自动读取 EXE 旁边旧 data 文件夹中的遗物列表和窗口位置。旧文件保持原样。升级时请先将旧 data 文件夹放在新版 EXE 旁，迁移完成后确认列表无误再移走。已有应用数据不会被旧文件覆盖。

- `saved_texts.json`：遗物及置顶设置。
- `window_position.json`：窗口坐标、尺寸。
- `backup-时间戳.json`：导入前的备份。

旧版 `saved_texts.txt` 格式尚未获取，因此未擅自转换；提供该文件后可补充无损迁移。

`npm test` 验证数据格式、非法数据拒绝和原子写入。当前交付环境无法执行 Windows EXE；Windows 启动和打包需要在 Windows 上验证。

铜色加深为 #ac754b。点击“精简置顶”仅显示四列遗物列表并保持窗口置顶，可缩小至 480×180；拖动列标题移动，边缘调整大小。按 Esc 或在列表空白处右键选择“退出精简置顶”恢复完整界面并取消置顶。列表复制、双击删除和右键换色仍可用。模式会自动保存，重启时恢复；删除后退出精简模式仍可点撤销。

## 1.4 独立精简窗口

点击“精简置顶”后打开独立窗口，并隐藏正常窗口。精简窗口只显示四列列表、始终置顶；拖动任意列标题可移动，拖动边缘可缩放。空白处右键“返回正常窗口”或关闭精简窗口会返回正常窗口。空白处右键“退出程序”会结束整个应用。

正常窗口右上角“设置”提供“精简窗口不透明度”滑块，20%–100%，数值越小越透明；对正常窗口无影响，修改后自动保存，下次精简窗口直接使用该值。两个窗口共用遗物数据，复制、双击删除、右键换色均保留。

窗口坐标尺寸分别保存在 data/window_position.json（正常）和 data/compact_window_position.json（精简），均位于原应用数据目录。切换不会将一个窗口的尺寸写给另一个。精简窗口首次默认 640×320，最小 400×160；保留原正常窗口位置记录。

## 1.4.1 游戏焦点修正
精简窗口使用不可获取焦点的窗口属性及 showInactive 显示方式，不调用 focus；正常保存不再重复显示／聚焦窗口。点击复制、双击删除及右键换色保留。精简模式不接收键盘焦点，因此请使用空白处右键“返回正常窗口”，不依赖 Esc。拖动列标题移动窗口。独占全屏游戏可能仍无法显示普通桌面悬浮窗口，可切换游戏为无边框窗口模式。

## 1.5 紧凑列表与穿透

- 精简模式不显示“几枚”计数和空列表提示，标题及条目更紧凑，最小窗口为 240×80；正常窗口的计数不变。
- 精简窗口空白区域右键：不透明度（20%–100%）、点击穿透、返回正常窗口、退出程序。
- 点击穿透开启后，左键／滚轮交给下方应用，不能复制、删除或拖动本窗口；右键仍打开助手菜单。要移动窗口，先在右键菜单取消穿透，再拖动列标题。
- 穿透只在精简窗口启用，正常窗口操作不受影响；设置自动保存。
- Windows 右键支持由随程序打包的 helper 处理，仅在穿透期间运行；通过系统鼠标接口拦截精简窗口矩形范围内的右键，窗口外的操作及左键交给系统，不记录输入。助手退出时自动停止。
- 首次启用需等待右键支持初始化（最久20秒）。初始化失败或退出时，会关闭穿透并恢复普通鼠标操作。
- 此实现需要 Windows 自带 Windows PowerShell 和 .NET；不需要额外 npm 原生模块。右键 hook 和游戏中的穿透需在 Windows 实测，当前环境无法验证这些系统行为。
