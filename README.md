# 遗物助手 · Relic Assistant

一个基于 Electron 的《Warframe》遗物记录工具。按古纪、前纪、中纪、后纪整理遗物，点击即可复制名称，也可以切换到精简置顶窗口，边玩边查看自己的遗物清单。

> 本工具由用户手动录入和管理清单，不会自动读取游戏仓库，也不提供遗物掉落或交易价格查询。

## 功能特点

### 四列遗物清单

- 按 **古纪 / 前纪 / 中纪 / 后纪** 分类显示。
- 纪元和铜、银、金三种标记颜色均通过按钮直接选择。
- 添加时自动将英文字母转为大写，例如 `b1 光辉` → `B1 光辉`。
- 同一分类内自动拦截重复名称，忽略英文大小写差异。
- 单击复制名称，双击删除，右键切换标记颜色。
- 正常窗口支持撤销最后一次删除。

### 独立精简窗口

- 点击 **精简置顶**，隐藏正常窗口并打开独立悬浮窗口。
- 仅保留四列列表，隐藏数量和空列表提示，减少屏幕占用。
- 最小尺寸 **240 × 80**，条目采用紧凑布局。
- 拖动列标题移动窗口，拖动边缘调整大小。
- 正常窗口与精简窗口分别保存位置和大小。
- 精简窗口采用不主动获取焦点的显示方式，减少对游戏焦点的影响。

### 透明度与点击穿透

- 正常窗口的 **设置** 面板可调整精简窗口不透明度。
- 精简窗口右键菜单也可调整不透明度，范围 **20%–100%**，数值越低越透明。
- 开启点击穿透后，左键及滚轮交给下方游戏或应用，右键保留助手菜单操作。
- 返回正常窗口、调整不透明度、关闭穿透或退出程序，均可通过精简窗口右键菜单完成。

> 开启穿透后，左键无法复制条目或拖动助手。需要操作列表或移动窗口时，先通过右键菜单关闭穿透。

### 自动保存与备份

- 清单、设置和窗口位置自动保存在本机。
- 支持导出、导入 JSON 备份。
- 导入前需确认，并自动备份当前数据。
- 支持首次启动时迁移早期 Electron 版本 EXE 旁的 `data` 数据。

## 快速开始

### 运行便携版

如果下载的是已打包的便携 EXE，双击即可运行，无需安装 Node.js。

如果使用 `win-unpacked` 目录运行，请保留整个目录，不要单独移动其中的 EXE。

### 从源码运行

安装 [Node.js LTS](https://nodejs.org/)，进入项目目录执行：

```bash
npm install
npm start
```

Windows 用户也可以直接双击 `start.cmd`，首次运行需要联网下载依赖。

### 打包 Windows 便携 EXE

```bash
npm run dist:win
```

或双击 `build-windows.cmd`。生成文件位于：

```text
dist/RelicAssistant-版本号.exe
```

## 操作说明

| 操作 | 功能 |
| --- | --- |
| 选择纪元和颜色，输入名称后按 Enter | 添加遗物 |
| 单击遗物 | 复制名称 |
| 双击遗物 | 删除条目；双击过程中也会触发复制 |
| 右键遗物 | 循环切换铜、银、金标记颜色 |
| 点击“精简置顶” | 隐藏正常窗口，打开精简窗口 |
| 拖动精简窗口列标题 | 移动窗口，需关闭点击穿透 |
| 精简窗口空白区域右键 | 打开窗口设置菜单 |
| 右键菜单“返回正常窗口” | 隐藏精简窗口，恢复正常窗口 |
| 右键菜单“退出程序” | 退出整个应用 |

精简窗口不接收键盘焦点，请使用右键菜单返回正常窗口，不依赖 Esc。

## 数据存储

Windows 默认数据目录：

```text
%APPDATA%\relic-assistant\data
```

| 文件 | 内容 |
| --- | --- |
| `saved_texts.json` | 遗物清单及窗口模式、透明度、穿透设置 |
| `window_position.json` | 正常窗口的位置和大小 |
| `compact_window_position.json` | 精简窗口的位置和大小 |
| `backup-时间戳.json` | 导入前的自动备份 |

数据不写入 EXE。移动或更新 EXE 不会携带或删除同一 Windows 用户目录中的记录；换电脑时请先导出备份。

首次迁移旧版 Electron 数据时，将原 `data` 文件夹放在新版 EXE 旁。仅当新的数据目录尚无清单文件时才会迁移，旧文件会保留。早期 Python 版 `saved_texts.txt` 暂不支持直接迁移。

## 游戏内使用

- 建议使用游戏的无边框窗口模式；独占全屏可能无法显示普通桌面悬浮窗口。
- 点击穿透保留右键菜单的实现面向 Windows，依赖系统自带的 Windows PowerShell 和 .NET。
- 穿透启用期间会运行右键辅助进程，仅拦截精简窗口范围内的右键，不记录输入；程序退出时停止。
- 若右键辅助功能启动失败，会取消穿透并恢复普通鼠标操作。
- 当前版本通过了数据和窗口逻辑的模拟测试；游戏内焦点、实际穿透及右键拦截仍需 Windows 实机验证。

## 技术与测试

使用 **Electron、JavaScript、HTML、CSS** 构建，数据以本地 JSON 文件保存。渲染进程启用上下文隔离，通过 preload 中的受限接口访问窗口、剪贴板和数据。

运行测试：

```bash
npm test
```

测试覆盖数据校验、文件保存、旧数据迁移、窗口切换、独立位置保存、透明度和点击穿透菜单流程。
